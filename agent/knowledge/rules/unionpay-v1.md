# 银联对账规则

## 内部单边

内部成功支付和配平账本分录存在，但银联渠道对账证据没有对应记录时，案件类型为内部单边。不得因为金额相同而关联其他渠道交易。

## 账本校验

每笔成功支付必须有借贷金额相等的账本分录。账本不平或业务引用不一致时，证据不完整，不能形成确定结论。

## 处理要求

内部单边案件应保留支付编号、账本业务引用和规则版本引用。执行案件解决前必须由人工确认，重复解决请求应被拒绝。
