# 支付宝对账规则

## 金额差异

渠道订单金额必须与内部成功支付金额完全一致。金额不一致时，应同时核对渠道交易号、支付状态和入账金额，不得只依据相似交易推断。

## 单边流水

渠道侧存在而内部支付不存在时，标记为渠道单边。内部支付存在而渠道对账文件没有对应记录时，标记为内部单边，不得自动核销。

## 处理要求

解决案件前必须保留支付和账本证据，并由人工确认处理方式。规则版本缺失或证据不完整时，不得给出确定的解决建议。
